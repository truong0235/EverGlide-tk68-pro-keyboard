Model: TK68 Pro kit - Epomaker Everglide

## keybinds
mod key: Fn

### Function:

Fn + [1 - =]: send F1 to F12 (row between Esc and Backspace butons)
Fn + Q/W/E: switch between bluetooth interfaces (each save per device, so save up to 3 devices)
Fn + hold Q/W/E: erase saved paired device and enter pairing mode
Fn + A/S: switch between Windows/MacOS keyboard layout
Fn + hold Esc (3-6 seconds): reset keyboard settings
Fn + Tab: Fn lock (now number row turn into F1 - F12 row, and Fn + [1 - =] will trigger special keys like volume up/down, brightest in/decrease, wip)
Fn + Delete: Insert
Fn + PageUp: Home
Fn + PageDown: End
Fn + Window: Hold Window button (?, need confirm)

### LEDs

Fn + Z: change border light mode (light modes, off)
Fn + X: change border light color
Fn + >/<: in/decrease border light brightest

Fn + Backspace: turn on/off keyboard led
Fn + Arrow Up/Down: in/decrease keyboard brightest
Fn + Arrow Right/Left: in/decrease keyboard light animation speed
Fn + \: change keyboard light mode
Fn + ]: change keyboard light color
